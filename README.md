# AI Image & Text Classification Dashboard 
---
**Description** - The following AI Image and Text Classification Dashboard project is built with Streamlit, using state-of-the-art Hugging Face models
to classify various texts as NEGATIVE or POSITIVE. However, to push the capabilities of the application, an image classification section is capable of
classifying a plethora of image objects into certain categories. 

## Application Prequisites
Since this application was built with the Pythonic framework Streamlit, the primary requirements for proper operation includes the following:
 - Streamlit
 - sqlalchemy
 - torch
 - pandas

## Running the App
Streamlit applications can be run by using the command below: 
  ``` streamlit run main.py```
**Note**: 'main.py' is the name of the primary file which runs the Streamlit pages. If any modifications are made to this file's name, alter the
'streamlit run' command. 😄
